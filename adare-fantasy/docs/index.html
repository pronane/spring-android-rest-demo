Twenty-Eight is a fantasy platform for the Ryder Cup: one brand and one scoring engine, with a new edition for every cup. The first is Adare 2027 — Adare Manor, Co. Limerick, 17–19 September 2027, the 46th Ryder Cup and the 100th anniversary of the matches.

What this page is. GitHub Pages can only serve static files, and Twenty-Eight is an application: accounts, a paid entry, a draft that has to be saved, a predictor, transfers and a live table — all of which need a server and a database. So this page is the gallery, and the app itself runs on a free host (or on your machine in one command). GO-LIVE.md has the ten-minute version — a Codespace, or Vercel with a free database.

Three free ways to try it for real

All of them keep the accounts, the database and the live table working.

0 · In a Codespace (fastest)

Open the repository in a Codespace — the container installs, applies the schema, seeds seven entries and builds, then starts the app on port 3000 with a public URL you can send to anyone.

About four minutes. Nothing to sign up for beyond the GitHub account you already have.

1 · On your own machine

One command installs Node, Postgres, the schema and the build — no admin rights.

git clone https://github.com/pronane/spring-android-rest-demo
cd spring-android-rest-demo/adare-fantasy
./install.sh          # Windows: .\install.ps1
./start.sh            # then open localhost:3000
npm run seed          # seven demo entries in the table

2 · A public link, free

Vercel's free tier runs the app and Neon's free Postgres holds it. Both are no-card sign-ups; the whole thing takes about ten minutes and the steps are in DEPLOY.md.

GitHub Codespaces is the other free option: open the repo in a codespace and forward port 3000 — no account anywhere else, and it sleeps when you close the tab.

No Postgres? It also runs on SQLite — one file, LIBSQL_URL=file:.data/twenty-eight.sqlite — or on Turso's free hosted SQLite. Same tables, same tests.

3 · Share it from your laptop right now

No deployment at all — a tunnel gives the machine in front of you a public URL in seconds:

./start.sh
# in another terminal:
cloudflared tunnel --url http://localhost:3000

Good for showing a few people today; it stops when your laptop does.

What is actually in the box

Games

  • Classic Six (6 players, 100m) and Captain's Dozen (12, 200m)
  • All 28 matches predicted, plus MVP / top scorer / rookie
  • Pinpoint: nearest the pin and longest drive
  • Transfers with windows, a free allowance and a −4 penalty
  • An armband you can give day by day

Money

  • Paid entry, prize pool and a sponsor-friendly private league
  • A ledger that adds up: cash in, platform share, pool
  • Refunds, prize settlement and payouts from the console
  • Demo checkout by default; Stripe when keys are set

Sign-in

  • Email one-time links
  • Google, Apple and Facebook — one account per verified email
  • Off until you add credentials, so nothing fails silently

Underneath

  • Next.js + TypeScript; Postgres, SQLite/Turso or a JSON file
  • 391 automated checks, including a 15-step browser test
  • Installers and a schema for macOS, Linux and Windows

Fan project

Twenty-Eight is an independent fan project. Not affiliated with the Ryder Cup, DP World Tour, PGA of America or Adare Manor. Checkout is a demo unless Stripe keys are configured — no card is ever charged and no card data is stored.
